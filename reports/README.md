# Generated reports

Everything in this folder is generated by `python -m nocturne build --date <call_id>`.
Do not edit by hand; edit the snapshot in `data/snapshots/` and rebuild.

| File | What it is |
|---|---|
| `2026-10-27_call.md` | The published call: bias, bands, levels, scenarios, base rates, provenance |
| `2026-10-27_levels.png` | Four-panel chart: last 12 closes, levels, predicted band, actual settlement |
| `2026-10-28_scorecard.md` | The postmortem: actual settlement, error, hit/miss, calibration |
| `2026-10-28_scorecard.png` | Predicted vs actual percentage change |
| `2026-10-27_dashboard.html` | Self-contained dashboard with embedded charts |

The dashboard is the shareable artifact. It embeds both PNGs as base64, so it works as a
single file with no external dependencies.
